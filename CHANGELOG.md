# Changelog

## 1.0.0

First release.

- Keeps addon chat commands selected after you send, the way `/p` and `/g`
  are. The command is prefilled when you open chat and saved across reloads
  and relogs.
- Typing another command removes the prefilled one; sending a normal message
  turns the sticky command off.
- Settings window to add and remove commands and clear the current one.
  Nothing is sticky by default.
- Minimap button (click to open settings, drag to move) and `/scc`.
  `/scc minimap` hides or shows the button.
